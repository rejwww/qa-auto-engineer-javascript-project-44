## Makefile - команды

Команда **make install** - полезна при первом клонировании репозитория (или после удаления node_modules).

Команда **make brain-games** - быстрый запуск игры.

Команда **make publish** - публикации пакета в npm для доступа установки другими участниками проекта.

Команда **make lint** - запуск Eslint (проверка кода на соответствие стандартам).

Команда **make brain-even** - быстрый запуск игры "Проверка на чётность".

Команда **start-by-name** - доступность запуска по названию игры. (предварительно выполнить команду chmod +x bin/name_game.js, где name_game.js - файл с игрой.)
